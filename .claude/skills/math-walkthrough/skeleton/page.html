§ Walkthrough — 代數 / 一元二次方程

公式解
一式一式推一次

$ax^2 + bx + c = 0$ 的根為什麼是 $\frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$？這一頁用配方法把它推一次。右邊一次只放一個式子，上面小字是它從哪一式來；講到哪一項，那一項就變色或推近，底下標出它的意思和代入的數字。

例子
$x^2 - 2x - 3 = 0$
代入
三組係數，其中一組沒有實根
方法
配方

往下捲 ↓

    $-\tfrac{c}{a} = 3$

    00 · 概觀

    一整面黑板

    右邊是整段推導，6 行。先把方程整理成 $x^2$ 開頭 01，補一塊把左邊變成完全平方 02，最後開根號 03。

    接著把三組係數代進去，看每一行的值 04。往下捲，一次看一式。

    $$\begin{aligned} \T{r1}{ax^2 + bx + c} &\T{r1}{{} = 0} \\ \T{r2}{x^2 + \tfrac{b}{a}x} &\T{r2}{{} = -\tfrac{c}{a}} \\[8pt] \T{r3}{x^2 + \tfrac{b}{a}x + \big(\h\big)^2} &\T{r3}{{} = \big(\h\big)^2 - \tfrac{c}{a}} \\ \T{r4}{\big(x + \h\big)^2} &\T{r4}{{} = \dfrac{b^2 - 4ac}{4a^2}} \\[8pt] \T{r5}{x + \h} &\T{r5}{{} = \pm\dfrac{\sqrt{b^2 - 4ac}}{2a}} \\ \T{r6}{x} &\T{r6}{{} = \dfrac{-b \pm \sqrt{b^2 - 4ac}}{2a}} \end{aligned}$$

    01 · 整理

    從一般式開始

    $a \ne 0$，不然就不是二次方程。根就是拋物線 $y = ax^2 + bx + c$ 碰到 x 軸的地方。

    例子 $x^2 - 2x - 3 = 0$：$a = 1$、$b = -2$、$c = -3$，拋物線在 $x = 3$ 和 $x = -1$ 穿過 x 軸。

    $$\T{q}{\T{a}{a}x^2 + \T{b}{b}x + \T{c}{c}} = 0$$

    01 · 整理

    除以 a，常數搬到右邊

    兩邊除以 $a$，讓 $x^2$ 前面是 1；再把常數搬到右邊。左邊剩 $x^2$ 和一個一次項，一次項的係數是 $\tfrac{b}{a}$。

    例子：$\tfrac{b}{a} = -2$，右邊 $-\tfrac{c}{a} = 3$。下圖把 $x^2$ 畫成邊長 $x$ 的正方形，$\tfrac{b}{a}x$ 是旁邊的長方形，切成兩半，一半搬到下面。

    $$\T{lhs}{x^2 + \T{ba}{\tfrac{b}{a}}\,x} = \T{ca}{-\tfrac{c}{a}}$$

    02 · 配方

    補上缺的那一角

    兩個半邊長方形圍著正方形，右下角缺一塊邊長 $\h$ 的小正方形。兩邊同時加上 $\big(\h\big)^2$，等式不變，左邊就補成一個完整的正方形。

    例子：$\h = -1$，補上的角落是 $1$，右邊變成 $1 + 3 = 4$。

    $$x^2 + \tfrac{b}{a}x + \T{add}{\big(\h\big)^2} = \T{add2}{\big(\h\big)^2} - \tfrac{c}{a}$$

    02 · 配方

    左邊是完全平方

    補完的正方形邊長是 $x + \h$，所以左邊寫成 $\big(x + \h\big)^2$。右邊通分成 $\frac{b^2 - 4ac}{4a^2}$，分子 $b^2 - 4ac$ 叫判別式。

    例子：判別式 $= 4 + 12 = 16$，右邊 $= 16/4 = 4$。

    $$\T{sq}{\big(x + \h\big)^2} = \frac{\T{disc}{b^2 - 4ac}}{\T{den}{4a^2}}$$

    02 · 配方

    判別式決定有幾個根

    左邊是平方，不會是負的。右邊的分母 $4a^2$ 也是正的，所以判別式是負的時候，等式不可能成立：沒有實根。

    往下捲，$c$ 從 $-3$ 加到 $3$：拋物線往上移，判別式 $4 - 4c$ 變小，兩個根往頂點靠攏；$c = 1$ 時剛好碰到 x 軸，之後就離開了。

    03 · 開根號

    頂點，加減一段距離

    兩邊開根號要記得 $\pm$，再把 $\h$ 移到右邊。$-\h$ 是拋物線頂點的位置，$\frac{\sqrt{b^2 - 4ac}}{2a}$ 是根離頂點多遠：兩個根對稱地站在頂點兩邊。

    例子：頂點在 $x = 1$，距離 $\sqrt{16}/2 = 2$，根是 $1 + 2 = 3$ 和 $1 - 2 = -1$。

    $$x = \T{v}{-\h} \pm \T{d}{\frac{\sqrt{b^2 - 4ac}}{2a}}$$

    04 · 代入三組

    把推導當函式跑三次

    回到黑板，把第 2 到 6 行當成一個函式，餵三組係數進去；每一格是那一行等號右邊的值。

    $2x^2 + 3x - 2$ 的右邊不是整數，照樣一路算到 $0.5$ 和 $-2$。$x^2 + 2x + 5$ 在第 4 行右邊變成 $-4$：一個平方等於負數，從這一行開始就沒有實根。

    05 · 回顧

    整面黑板，填上三組係數

    整段推導只做了一件事：補一個角，讓左邊變成完全平方。判別式的正負決定開不開得了根號；橘色是 $x^2 + 2x + 5$ 斷掉的地方。
